# Follow the signal

Studio’s reference works through recurring objects, camera changes that explain the product, and quiet passages between animated scenes. Tincan adapts those principles into a communications workshop: silver cans, cobalt and vermilion signals, cool porcelain, and oversized Space Grotesk typography. No reference artwork or implementation code was reused.

The request travels through a private relay, Council turns independent answers into a verdict, and the final phone receives the result. The four-example phone demo advances with native scroll and can also be selected directly. Generated artwork supplies material and lighting; live DOM text supplies readable messages and controls. Motion-off mode exposes full transcripts and a static Council storyboard.

Original generated assets and exact prompts are recorded in [artwork.md](artwork.md). The baseline, recovery procedure, and verification limits are recorded beside this file.
