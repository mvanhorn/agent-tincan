Site access

Agent Tincan reads and sends only on sites Chrome has granted it. Grant a site here before its web agent or history reads can use it; Chrome asks you to confirm.

    Chrome profile name

    Leave this empty if you use Agent Tincan in one Chrome profile. If two Chrome profiles are signed in to different accounts, give every profile but one a name here, then run that profile's web agents with tincan web serve --profile <name>. The name stays in this profile only.
